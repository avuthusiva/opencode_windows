How this page works

Every function below has the same name and the same job as in sudoku.py: parseGrid, candidates, findBestEmpty, solve, countSolutions, generatePuzzle.

  • A grid is a list of 9 rows, and each row is a list of 9 numbers. 0 means empty.
  • candidates collects the digits used in the row, the column and the box, then returns the digits 1 to 9 that are left.
  • solve guesses a digit in the cell with the fewest options, calls itself for the rest of the grid, and takes the guess back when the rest fails.
  • generatePuzzle fills an empty grid, then blanks cells one by one and keeps a blank only when the puzzle still has exactly one answer.

A browser cannot call Python, so the Python results are copied into puzzles.js as plain text. That file is a normal script, the page just reads it.
