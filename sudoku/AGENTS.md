# Project guide

## What this is

A small Sudoku learning project. Python holds the logic, and `sudoku.html` is the
same logic again in JavaScript so it can run in a browser. The point is to see how
a few rules become a working program.

## Layout

```
opencode/
└── sudoku/
    ├── src/
    │   ├── sudoku.py        all logic: parse, rules, solver, counter, generator, CLI
    │   ├── export_to_js.py  runs the logic and writes data/puzzles.js
    │   ├── db.py            DuckDB layer and a small command line
    │   └── schema.sql       the four tables
    ├── tests/
    │   └── test_sudoku.py   20 plain checks, no test framework
    ├── data/
    │   ├── puzzles.txt      sample puzzles, one line each
    │   ├── puzzles.js       generated by export_to_js.py, do not edit by hand
    │   └── sudock.duckdb    local database, ignored by git
    ├── web/
    │   └── sudoku.html      the page, standalone, no server and no internet
    └── README.md            longer notes about the code
```

## Commands

Run these from the `sudoku` folder:

```
python src/sudoku.py                   # generate one puzzle, then solve it
python src/sudoku.py --clues 28        # ask for a clue count
python src/sudoku.py data/puzzles.txt  # solve every puzzle in a file
python tests/test_sudoku.py            # run the checks, must print "All checks passed"
python src/export_to_js.py             # refresh data/puzzles.js and the database
python src/db.py --init                # create data/sudock.duckdb and its tables
python src/db.py --tables              # list table names
python src/db.py --show                # show columns and a few rows
```

## Database

`sudock.duckdb` holds four tables: `puzzles`, `games`, `moves`, `settings`.
Every table has `created_at` and `updated_at`. DuckDB has no triggers, so any
UPDATE statement must set `updated_at = current_timestamp` itself.

## Rules for this project

- `sudoku.py` is the source of truth for the logic. Keep the JavaScript in
  `sudoku.html` matching its function names and behaviour.
- Never edit `data/puzzles.js` by hand. It is generated by `export_to_js.py`.
- Run `python tests/test_sudoku.py` after changing `sudoku.py`, and report the result.
- Keep the page standalone: no build step, no server, no CDN links.
- This repo is public. Do not put real credentials or personal data in it.
